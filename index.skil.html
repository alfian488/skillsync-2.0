Saya butuh tips untuk membuat portofolio Data Analysis menggunakan SQL. Proyek apa yang bagus untuk pemula?

Tentu! Berikut 3 ide proyek portofolio SQL yang menarik bagi rekruter:

  • Analisis Penjualan E-commerce: Gunakan dataset publik (misal Kaggle) untuk mencari tren penjualan bulanan dan produk terlaris.
  • Customer Churn Analysis: Buat query untuk mengidentifikasi pola pelanggan yang berhenti berlangganan.
  • HR Dashboard Data: Analisis demografi karyawan dan tingkat *turnover*.
